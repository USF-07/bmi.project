BMI Calculator Program

(Description)
A C++ program for calculating Body Mass Index (BMI) and classifying users' health status.
The program allows users to input their personal data (weight and height) and calculates their BMI along with the appropriate health classification.

(Key Features)
-> BMI Calculation - Accurate BMI calculation using weight (kg) and height (cm)
-> Data Storage - Stores records for up to 100 users
-> Search System - Search for previous users using ID
-> Health Classification - Displays health status (underweight, normal, overweight, obesity, etc.)
-> User-Friendly Interface - Simple and clear menu system

(Technologies Used)
- Data Structures for organizing user information
- Static Arrays for storage
- Specialized functions for each task
- Basic input/output handling
